# Folder foto artikel

Taruh semua foto artikel di folder ini, misalnya:

- `public/images/artikel/foto-sampul.jpg` → di metadata artikel, `cover: "/images/artikel/foto-sampul.jpg"`
- `public/images/artikel/isi-artikel-1.jpg` → di dalam isi artikel: `![keterangan](/images/artikel/isi-artikel-1.jpg)`

Catatan: path selalu diawali `/images/artikel/...` (tanpa `public`).
