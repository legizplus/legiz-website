# LEGIZ.ID Company Profile Website

Production-ready React/Vite website for PT Legal Izin Plus Indonesia.

## Development

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production Build

```bash
npm run build
```

The deployable static files are generated in:

```text
dist/
```

You can upload the contents of `dist/` to static hosting such as Vercel, Netlify, Cloudflare Pages, cPanel static hosting, or any web server.

## Preview Production Build

```bash
npm run preview -- --port 4173
```
